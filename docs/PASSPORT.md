Только то, чем модель отличается от остальных моделей семейства. Доступы, сервер, выкладка, откат и общие грабли —
в справочнике семейства; подробности этой модели — `docs/MANUAL.md`. Состояние (версия книги, квартал, версия миров,
коммит, выпуск) несёт выпуск: `meta` в `/api/model`. Цены ниже — из записей решений на дату записи (точка / медиана,
₽ на акцию); «ось» — точка на концах оси полосы и доля оси в полосе по книге 1.2 (раздел 0, таблица осей; раздел 13);
текущие цены суждений — экран «Допущения» и раздел 13 книги.

## 2. На чём стоит число

Разрыв с рынком создают четыре бизнес-суждения внутри диапазонов книги: поддерживающий capex, долгосрочная маржа,
долгий реальный LFL, β_u (`docs/DECISIONS.md`, часть 5, итог). Рыночная цена в выборе центров не участвует.

| Суждение | Центр | Правило центра | Цена альтернативы |
|---|---|---|---|
| Поддерживающий capex (A-K1) | стационар base 2,77 % выручки с замещением; ось ±0,4 п.п. | середина коридора стоимости замещения (часть 5, п. 13) | прежний центр у нижнего края коридора: переход стоил −260,5 / −208,5; ось ±0,4 п.п. (все уровни): 3 883 / 2 763 точки (26,9 %) |
| Долгосрочная маржа (A-C0, цели 2031–2035 и LT режимов) | цели в долгую 5,51 / 6,40 / 7,03 / 7,70 % (стресс / дно / частичная / полная), вероятности 37 / 32 / 22 / 9 %, E[m_LT] 6,33 %; «Дом Лента» — явным слагаемым; веса классов — правило w_I 0,66 | убыток ребрендинга — переходное отклонение, а не состояние (часть 2, C17); правило весов зарегистрировано до подсчёта (C18, часть 5, п. 19) | убыток DIY как состояние ≈−130 (лист); суждение поверх правила +35 / −100 (лист); снятая находка margin-03 — до −50; ось −0,6…+0,4 п.п.: 2 797 / 3 676 точки (19,3 %) |
| Долгий реальный LFL (A-R1 перенос инфляции в чек k, A-R2 долгий сдвиг s) | s LT 1,5 п.п. (состояния 0,5 / 1,5 / 2,0) при k 0,55 (0,50 / 0,55 / 0,60) и трафике LT −0,3 % — реальный LFL в мире N ≈ −0,4 % в год | s = реальный LFL + π_N − k × прод. ИПЦ_N − трафик; s по истории при k 0,55: 2016–2019 — 0, 2П23–2П25 — +2,6…+5,1, 1П26 — +2,7, 2 кв. 2026 — ≈+2,1 (скидки ради трафика); k — МНК по кварталам 2016–2к26 без 2019–2021 (0,44), с весами форматов 1П26 (0,59) | ось s 1,0 / 2,0 п.п.: 2 961 / 3 725 точки (11,2 %); k ±0,1 без пересчёта s: 2 910 / 3 778 точки (раздел 13) |
| Бета активов β_u (A-V1) | 0,52 | якорь X5 × операционный рычаг «Ленты» на проформе через EBITDAR с разрычаживанием аренды (часть 2, E30) | ось 0,45 / 0,70: 3 508 / 2 914 точки (7,1 %); без разрычаживания аренды 0,58 — не считалась |
| Дисконт за управление g | 6,415 % | медиана Монте-Карло суммы независимых каналов, неподвижная точка с медианой (часть 5, п. 3 и 23; часть 6) | канал ликвидности и листинга поднят до 4,0 % — −17,5 / −10,9; канал оферты = 0 — −35,1 / −22,3 |
| Целевой рычаг лестницы L | 1,47 | отчётный ЧД/EBITDA на 31.12 базовой клетки ≈1,0× по гайденсу (часть 5, п. 14) | переход к правилу +146,8 / +124,5 |
| Налоговая премия ускоренной амортизации (A-T5) | 0,41, ось 0,31–0,51 | в центре свидетельств книги 2022–2025 (часть 5, п. 2) | прежний центр 0,2: переход +82,0 / +79,9 |
| Миры ставок и их веса | общая запись семейства, веса 35/45/20, λ 0,5 | побайтово запись книги-источника; якоря — выход правил рецепта (часть 8) | против одного дня снимка −25,2 / −25,4; против проекта ОНДКП −11,9 / −11,5 |

Цена альтернативы — сдвиг, который дало решение против прежнего значения, одиночно и на книге своей даты; возврат
к прежнему — примерно тот же сдвиг с обратным знаком.

Развилки не в центре (книга, раздел 16; `docs/DECISIONS.md`, части 5–6):
- Конвенция уровня эффективной площади: непрерывный индекс вместо сброса с двумя плотными когортами — −32…−49. Не
  взято: обе защитимы, текущая откалибрована листом.
- «Низкий» capex без догоняющих реконструкций — −103 / −35. Оставлено как в книге-источнике.
- Маржа новой и закрываемой площади — −28…+253. Ключ не вводится: сегментной маржи компания не раскрывает.
- Правило T0 класса E — −13…+53. Правило до подсчёта защищает от подгонки.
- Номинальный лимит кредитных линий как триггер неустойчивости — −221 точки. Не взято: лимит одной даты не
  ограничивает путь долга растущего бизнеса; неустойчивость ловит порог 4,0× ЧД/EBITDA.

## 3. Чем экономика эмитента отличается от ядра сектора

Ядро — копия ядра Магнита со своей частью; цена — внутренняя стоимость, а не колл.

| Особенность | Как учтена | Чем включается | Цена |
|---|---|---|---|
| Умеренный рычаг (ЧД/EBITDA якоря 1,39×) | цена = max(V0 − D, 0)·(1 − g)/акции, гейт `limited_liability`; колл удалён из кода | `valuation.headline.method: intrinsic` | опционная часть ≤ 0,2 % цены (часть 3) |
| Сеть из восьми сегментов, проформа с «О'КЕЙ» | сегменты по строкам отчёта: `yoy`, `level` («Дом Лента»), опт прибавкой к LFL; эффективная площадь когорт | ключи сегментов книги, `revenue_se`, `new_area_dense_cohorts` | маржа якоря проформы ±0,2 п.п. — 3 163 / 3 485 точки (книга 1.2, A-C7) |
| Ускоренная налоговая амортизация | премия × capex сразу, остальное линейно; стационарная разница в терминале | `tax.capex_tax_premium_share` | +167 при 0,2 против без механизма (лист, книга 1.0) |
| Запертые убытки купленных юрлиц | пул с даты присоединения, haircut 0,25 | `tax.acquired_nol` | +11 против зачёта сразу (лист) |
| Дивидендная лестница положения 2021 г. | выплата по году в 1П следующего, ступень по отчётному ЧД на 31.12 | `financing.dividend_timing: annual_next_h1`, `financing.dividend_net_debt_basis: reported` | −66 и +4 точки (часть 4) |
| Пут «Реми», остаток «ОБИ», займы выданные, справедливая стоимость фиксированного долга | строки моста; компенсирующий актив «Реми» — парой в ОК | `bridge.items` | двойной счёт «ОБИ» стоил бы ≈33; одиночный актив «Реми» +19 (часть 2) |
| Денежный LTIP | возобновляемый поплавок в ОК, строки моста нет | `nwc.anchor_level`, `hold` | +32,7 / +31,9 (часть 5, п. 22) |
| Сезон ОК внутри года | перекат ЧД квартальными весами | `nwc.quarter_share` | −6…−9 против линейного (лист) |
| Лимит кредитных линий | справка, не триггер | `valuation.distress.credit_limit_trigger: false` | снятие обрыва +145 точки (часть 4) |
| Терминал | выручка от площади выхода, D&A когортами, уровни ОК скользящие, налог без рычага не ниже нуля, щит на среднем отчётном рычаге цикла | `valuation.terminal.revenue_base: exit_area`, `da_convention: cohort_explicit`, `boundary_levels: rolling`, `tax_floor: exact`, `shield_leverage: cycle_average` | +15,8 / +13,8; +4,52 / +4,62; −2,48 / −2,28; −1,05 / −1,53; −36,5 / −37,6 |

Правки общего кода, которых нет у образца: в документах не названы. Движок приёма миров — побайтово образец
семейства (`docs/CHANGELOG.md`, выкладка 22.11.2026); рецепт миров — семейная копия; индекс вилок — общий модуль.

## 5. Отступления от шаблона семейства

- Выпуск публикуется в отдельный публичный репозиторий данных, а не в R2 или ветку кода (`docs/DECISIONS.md`, запись 9).
- Юниты `lenta850-*`, каталоги `lenta-850`. Расписание: сбор ≈04:20 UTC каждый день, вечерний такт по будням ≈17:25 UTC,
  пересборка `*:07,22,37,52` при новом коде в `model`, `indicators`, `ops`, `data/assumptions`, `data/facts`,
  `requirements.txt` (без `*.md`).
- Тесты такта — метка `tact`, цель ≤ 3 минут; «в будущем»: сервер по понедельникам +60 дней, CI раз в месяц +180.
- Параллельных тестов, команды перевывода и бюджета времени тестов нет (лист сектора, раздел 8).
- Особых сертификатов в документах нет.
