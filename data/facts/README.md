# Факты отчётности

Факты «Ленты» с источником в первичке (sha256 из манифеста первички, страница, цитата). Первичка (PDF/XLSX) в репозиторий не кладётся — только её хэши и выписки чисел; описание — `docs/FACTS.md`, сборка — лист `data/assumptions/evidence/book-1.0/facts/` (`build_facts.py`, канон проформы якоря — `canon.py`).

| Файл | Что | Кто читает |
|---|---|---|
| `accounting_base.json` | полугодия и кварталы 2018–2026 в базах IAS 17 и МСФО 16 (выручка, EBITDA, проценты, долг) | слой индикаторов: эталоны журнала, ретро-проверка, канал процентов |
| `anchor.json` | якорь 30.06.2026: отчёт и проформа (выручка, EBITDA, D&A, LTM — один канон, решение ведущего A12), гайденс 2026 | книга (A-D), слой индикаторов (гайденс) |
| `bridge_balance.json` | статьи моста на 30.06.2026 (пут «Реми», остаток «ОБИ», LTIP, НДУ, займы выданные, компенсирующий актив, справедливая стоимость долга); ограниченных средств — 0 | книга (`bridge.items`), тесты книги |
| `debt.json` | долг до МСФО 16 на 30.06.2026: транши, облигации «О'КЕЙ», линии, справедливая стоимость | книга (корзины A-F1r), `debt_register.json` |
| `debt_register.json` | реестр долга схемы `debt-register-v1` (транши с условиями, касса) — отчётный слой: стена рефинансирования, чувствительность к ключевой, канал процентов (`model/financing.py`); оценку не меняет | выпуск, слой индикаторов |
| `inorganic.json` | сделки 2021–2026 (периметр, цена, принятый долг, проформа), разрывы периметра | книга (D3), `indicators/perimeter.py` |
| `peers.json` | аналоги на одной базе IAS 17 (X5, Магнит — публичные databook; решение ведущего F33), цели инвестдомов | книга (`market.peers`, `market.sellside_*`), выпуск |
| `shares.json` | акции в обращении, квазиказначейские, EPS | книга (A-D1) |
| `strategy.json` | цели стратегии-2028 (выручка, маржа, ЧД/EBITDA, capex, открытия по форматам; презентация стратегии, с. 32–33, sha256 из манифеста) — только сверка, в ядро не входят | выпуск (`strategy`), `model/checks.py` (основание коридора capex) |
| `sources.json` | реестр источников с sha256 и sha256 производных файлов этого каталога (`derived_files`; тест `tests/test_facts_manifest.py` держит их равными файлам на диске) | сверка |

Эмитента набора данных называет `data/issuer.json` (необязательно; по умолчанию — Лента, `indicators/issuer.py`).
