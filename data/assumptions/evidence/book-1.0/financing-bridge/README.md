## 5. Перекат ЧД на дату оценки

Правило переносимого ядра: ЧД(оценки) = ЧД(якоря) − w·(FCFF + щит − I) текущего полугодия, EV берёт (1 − w) того же полугодия, w = доля дней (на 18.09 — 0,4293). У Ленты второе полугодие делает 4 кв.: ΔОК 3 кв. / 4 кв. = −4,4 / +23,6 (2024), −0,9 / +25,0 (2025); поток до долга 3 кв. — +0,5 % и −11,8 % потока 2П. Пул долей ОК по кварталам: **1 кв. 1,180 · 2 кв. −0,180 · 3 кв. −0,123 · 4 кв. 1,123**; вес ОК на 18.09 = −0,123 × 79/92 = **−0,105** против 0,429 линейно.

При ΔОК 2П2026 = 20–30 млрд линейный перекат занижает ЧД на 18.09 на **10,7–16,0 млрд** и завышает цену на **≈6–9 ₽** (только время: часть высвобождения 4 кв. считается уже полученной; r_u 18,5 %). **Предложение:** ключ `nwc.quarter_share: {Q1: 1.18, Q2: -0.18, Q3: -0.123, Q4: 1.123}` (блок nwc — владелец лист nwc-tax/ведущий; в §4 схемы его нет): w для ΔОК = доля квартала, внутри квартала — линейно по дням; прочие статьи — линейно; **один и тот же w** в перекате ЧД и в доле текущего полугодия в EV (тест: капитал клетки не зависит от w, кроме дисконтирования). Без ключа — подпись на витрине «ЧД на дату оценки — перекат линейно по дням; факт 30.09 будет выше на ≈11–16 млрд (высвобождение ОК — в 4 кв.)».

## 6. Правила для ядра (P2)

1. **Корзины.** P0 = Σ корзин = 141,923 (основной долг; проценты к уплате 0,66 — в долге, не в корзинах). Живая сумма корзины b в периоде p: L_b = share_b·P0 при p ≤ until_b, иначе 0. Если валовой долг модели D(p) < Σ L_b — все L_b × D/ΣL. Новый долг N = max(0, D − ΣL). Ставка: [Σ L_b·r_b + N·r_new]/D, r_b = fixed или key(p) + key_plus, r_new = fixed_share·(ОФЗ 3 г. мира + spread_fixed[credit]) + (1 − fixed_share)·(key + spread_float[credit]). Справедливая: у корзин = r_b (избытка нет), у нового долга — со `spread_fair`. Иначе премия старых купонов считается дважды (корзины + `fixed_debt_fv_premium`).
2. **Лестница.** Для года ≥ `dividends_from_year`: λ = ЧД до выплаты / EBITDA LTM; room = L·EBITDA_LTM − ЧД до выплаты; FCF = ЧД(p−1) − ЧД до выплаты; потолок ступени (первая ступень с λ < max_leverage; null — +∞) = +∞ или payout_max·max(FCF, 0); выплата = min(max(0, room), потолок). При L = 1,0 совпадает с переносимым правилом ядра «излишек над L»; лестница работает только при L > 1,0 (между 1,0 и L платится не больше FCF — ЧД не растёт от дивидендов). Терминальный долг щита — L·EBITDA_T (с проверки пакета аудита 30.09.2026 — средний отчётный рычаг цикла выплат клетки × EBITDA_T, `valuation.terminal.shield_leverage: cycle_average`).
3. **Мост.** Платёж в пути ЧД выводится из строки: amount·(1 + rate)^n в `settle_period`, n — полугодий от `bridge_as_of` до начала периода (актив — со знаком минус и с учётом haircut); в требованиях на дату оценки — amount·(1 − haircut)·(1 + rate)^(полугодий от `bridge_as_of`), пока `settle_period` не закрыт; строки без `settle_period` — постоянны до перезаякоривания. Перекат ЧД платежей строк не содержит. Тесты: пут дважды (ОК + мост), НДУ «Реми» дважды (НДУ + пут), компенсирующий актив дважды (ОК + мост), `nci_ex_remi` + доля «Реми» = строке НДУ баланса.
4. **Лимит линий** = `facts.anchor.net_debt` + `facts.anchor.cash` (142,584 — валовой долг на ту же дату) + `facts.undrawn_credit_lines` (283,863) = 426,447 — ключ обязательный, без `.get(…, 0)`.

## Возражения ведущему

1. **«Ограниченные денежные средства ≈2,47 млрд» (D13) — таких нет.** МСФО 1П2026 прим. 17 (с. 29): ограниченные средства (аккредитив «Реми») — «–» на 30.06.2026 (8,191 на 31.12.2025, переведены продавцу); 2,471493 — «компенсирующий актив» из распределения цены «Реми» (FY2025 прим. 8, с. 48; прим. 20, с. 62). Ярлык «Restricted cash» — ошибка датабука (лист BS, строка 32). Решение листа: актив возмещения, парный налоговым обязательствам «Реми» в ОК; в мосте haircut 1, в ОК — вместе с парой.
2. **«Ставка займа Севергрупп ниже рыночной, ≈8,7–10,8 %» (D5, D12) — не установлено.** Начисленные 262,9 млн задают ставку только вместе с датой выдачи: 8,7 % (25.05) … 11,2 % (02.06) … ≈15 % (≈09.06 — рынок). МСФО прим. 20 прямо пишет «по рыночным процентным ставкам»; займ ниже рынка от акционера по МСФО 9 признаётся по справедливой стоимости с разницей в капитал — такой записи нет. Любая субсидия уже внутри строки справедливой стоимости (+2,70 на весь фиксированный долг); отдельной строкой её не вводить. Цена вопроса для ставки корзины — ≈1 ₽/п.п.
3. **«Займы выданные 3,34 — схема «заём продавцу до сделки» (D13)»** — скорее не новая сделка, а остаток переуступленного займа компании под общим контролем после зачёта в цену «ОБИ» (реконструкция до 0,8 млн, лист facts — то же). Правило NPV = 0 даёт haircut 0; вероятен зачёт с остатком «ОБИ» 4,07 (тот же контрагент) — нетто моста от этого не меняется.
4. **Тест «НДУ в мосте = строке баланса» (D13) противоречит «НДУ без доли «Реми»».** Верная форма: `nci_ex_remi` (0) + доля «Реми» (0,991707) = строка НДУ баланса.
5. **Перекат ЧД** — рекомендую квартальные веса ОК (ключ `nwc.quarter_share`, в §4 схемы отсутствует): цена −6…−9 ₽ против линейного, ЧД на витрине +11…16 млрд — ближе к отчёту за 3 кв. Условие — один w в ЧД и в EV.
6. **Схема `rate_baskets`**: поле `rate` задано отображением `{fixed: x}` / `{key_plus: s}` (иначе плавающую корзину не записать); `fixed_share` сохранён для долга вне корзин (смысл уточнён); правило «справедливая ставка корзины = своя» обязательно — иначе премия старых купонов дважды.
7. **Триггеры АКРА 2,0х/4,0х — не пороги неустойчивости**: другая база (общий долг без аренды / FFO; долг с арендой / FFO); 2,0х ≈ ЧД/EBITDA IAS 17 1,2–1,6 — это понижение рейтинга (спред stress) у верхней границы оси L, а не издержки 10 % EV. Порог неустойчивости оставлен 4,0×.
