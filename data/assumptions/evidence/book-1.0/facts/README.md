# Лист «факты» книги 1.0 (Лента 850): база фактов якоря 30.06.2026

**Что.** Машиночитаемая база фактов для книги 1.0 и ядра: отчётные формы 2018H1–2026H1 и 2020Q1–2026Q2 в двух базах, якорь 2026H1 с проформой «О’КЕЙ» (D3), акции, реестр долга, строки баланса для моста, периметр M&A 2021–2026, аналоги на одной базе, манифест источников. Плюс проверка тождеств и фрагмент машинной книги.

**Метод.**
1. Датабук читается целиком (листы PL, BS, CF, Financials quarterly, Debt, Operating Results); у каждого числа — ссылка на ячейку («PL!AE10»). 2П = FY − 1П (помечено `kind: calc`). Единицы: тыс. ₽ → млрд; квартальный лист — млн ₽; лист Debt — тыс. ₽ до 2019 и млн ₽ с 2020.
2. Числа примечаний МСФО (230) и цитаты (17) записаны в реестр `NOTE_FACTS`/`NOTE_QUOTES` с документом и страницей; сборка проверяет каждое по тексту страницы. Все подтверждены.
3. Блок МСФО 16 датабука сверяется с первичными формами на якорных датах: 352 из 369 чисел найдены (остальное — SG&A вне форм, ±1 тыс. ₽, переклассификация ОК 1П2025).
4. sha256 каждого файла пересчитывается и сверяется с `MANIFEST.md` (17/17).
5. Производные (проформа, LTM, трек НДУ, остаток «ОБИ», реконструкция займов выданных) считаются в скрипте и проверяются тождествами.

## Возражения ведущему

1. **D13 «ограниченные денежные средства ≈2,47 млрд».** На 30.06.2026 ограниченных денежных средств нет: аккредитив «Реми» 8,191 переведён продавцу, в прим. 17 (с. 29) на 30.06.2026 — «–». 2,471493 — «Компенсирующий актив», признанный при покупке «Реми» (КФО 2025 прим. 8 с. 48, строка «Прочие оборотные активы» распределения цены) напротив налоговых обязательств «Реми» 2,932 + 1,257. Это возмещение продавцом под налоговые риски, не деньги. Датабук называет строку «Restricted cash» (DB-5). Предложение: строку моста переименовать в «компенсирующий актив», по умолчанию 0 (он гасит обязательство, которое сидит в налогах внутри ОК); ненулевой — только в паре с этим обязательством вне ОК.
2. **D13 тест «НДУ в мосте = строке баланса».** Вся НДУ баланса (0,991707) — доля «Реми»: 0,978523 при покупке − 0,042919 + 0,056103. С правилом «НДУ без доли «Реми»» тест в буквальной формулировке ложен. Формулировка: «НДУ в мосте = строка баланса − трек «Реми» = 0».
3. **D8 ссылка «МСФО прим. 21».** В 6М2026 акции — прим. 18 (с. 29–30), средневзвешенное число — прим. 19 (с. 30); прим. 21–22 — нумерация КФО 2025.
4. **D3 «705,26».** Точное значение — 705,248956; 705,26 получается из округлённых слагаемых. Проформа раскрыта только по «О’КЕЙ»: первые недели «Дом Ленты» в 1 кв. 2026 не приведены (проформы нет), в DECISIONS записать, что периметр якоря = 30.06.2026 без доприведения DIY (DIY в режиме level; вклад в выручку LTM ≈2–4 млрд при отрицательной марже).
5. **§4 `facts.revenue.pro_forma` 2025H1/2025H2.** Группы на периметре 30.06.2026 для 2025 нет в первичке: у «ОБИ» до сделки выручки нет вовсе, у «Молнии» до 24.06.2025 — только годовая 19,8. Фрагмент даёт сумму сегментов без diy (606,3 / 689,7; отношение 2П/1П 1,137 против 1,147 в 2025) и помечает это.
6. **D7 источник цены.** В primary-файле истории ISS (`iss_history_LENT_2026-06-26_2026-09-25.json`) нет LEGALCLOSEPRICE; 1 619,5 взята из сырого ответа `research/_work05/LENT_TQBR.json`. Файл с legal close нужно положить в `reference/primary` с sha256 в MANIFEST (урок Д11).
7. **Аналоги X5 и Магнит (D15/D16) — решено.** Строки аналогов — публичные отчётные данные эмитентов (databook 1H 2026) со ссылкой на первоисточник: в публичном репозитории допустимы (решение ведущего F33; разрешение — `tests/test_public_hygiene.py`). Databook X5 и Магнита — в первичку с sha256 (решение ведущего A5; сейчас числа — транскрипция из записи книги-источника).
8. **D11 «≈4,07 млрд внутри торговой и прочей кредиторки».** Местоположение остатка «ОБИ» не раскрыто; «вероятно, внутри кредиторки за ОС, НМА и приобретения бизнеса 9,12». Мутационный тест «ровно один раз» должен опираться на это как на допущение листа nwc.
