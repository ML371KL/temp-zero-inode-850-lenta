# Проверка листа «факты» (книга 1.0)

## Как воспроизвести

Python 3.12, зависимости: `openpyxl`, `pypdf`, `pyyaml` (венв `book-draft/.venv`).

```
cd book-draft/evidence/book-1.0/facts
set PYTHONIOENCODING=utf-8
set LENTA_PRIMARY_DIR=<путь к reference/primary>     # по умолчанию — ../../../../reference/primary от этого каталога
set LENTA_RESEARCH_DIR=<путь к research>              # по умолчанию — ../../../../research
..\..\..\.venv\Scripts\python.exe build_facts.py      # → book-draft/facts/*.json, out/build_log.txt
..\..\..\.venv\Scripts\python.exe check_facts.py      # → код 0; полный вывод — out/check_output.txt
..\..\..\.venv\Scripts\python.exe make_fragment.py    # → book-draft/fragments/facts.yaml
```

Необязательно: `MAGNIT_850OA_DIR` — каталог репозитория 850oa для справочной сверки строки X5 (`peers.json → check_vs_850oa`); без него сборка не падает.

**В репозитории** лист лежит в `data/assumptions/evidence/book-1.0/facts/`, и умолчания путей (выведенные для `book-draft`) не годятся — три каталога задаются явно: `LENTA_PRIMARY_DIR`, `LENTA_RESEARCH_DIR` и `LENTA_FACTS_OUT` (каталог выхода; для сверки — временный, для новой версии фактов — `data/facts`); затем `canon.py <каталог выхода>` (канон проформы якоря; он же обновляет sha256 `anchor.json` в `sources.json`). Интерпретатор — с `pypdf` (в окружении репозитория его нет: такт и CI лист не запускают). Проверено 06.10.2026: сборка → канон дают `accounting_base.json`, `anchor.json`, `shares.json`, `debt.json`, `bridge_balance.json`, `inorganic.json` бит в бит равными `data/facts`; `peers.json` отличается только справочным блоком `check_vs_850oa`, если каталог 850oa не той версии.

## Что обязано держаться

**Сборка (`build_facts.py`, код 2 при нарушении):**
- sha256 каждого из 17 документов совпадает с `MANIFEST.md` (у `.txt` пресс-релиза — префикс sha в описании строки `.html`). Лог: `документов: 17, хэш = MANIFEST: 17`. Несовпадение — отказ сборки кодом 2 до разбора документов (`manifest_gate`; до 06.10.2026 сборка только печатала «ВНИМАНИЕ» и завершалась кодом 0 — внешний аудит, D01).
- Каждое из 230 чисел реестра `NOTE_FACTS` найдено на своей странице по текстовому слою PDF (или в тексте отчёта эмитента), каждая из 17 цитат `NOTE_QUOTES` — дословно (с точностью до пробелов). Лог: `не найдено: 0`.

## Известные ограничения проверки

- Блок IAS 17 с 2019 года аудитом не проверяется; сверка с первичкой возможна только для МСФО 16 и для производных (выручка одинакова в обеих базах).
- Цена книги и аналоги опираются на файлы вне `LENTA_PRIMARY_DIR` (`research/_work05`, транскрипция 850oa) — их sha256 записаны в `sources.json`, но в MANIFEST их нет.
- Кандидаты проформы (`pro_forma_candidate` в `anchor.json`) — расчёты и суждения этого листа; окончательные значения даёт лист margin (EBITDA, маржа, D&A) и network (базы сегментов, эффективная площадь).
