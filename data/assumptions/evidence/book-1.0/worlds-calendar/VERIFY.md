# VERIFY — лист «Миры ставок и календарь» (книга 1.0 «Ленты»)

## Как воспроизвести

Окружение: Python 3.12 (`H\book-draft\.venv`, PyYAML 6.0.2), `PYTHONIOENCODING=utf-8`, каталог — этот лист.

```
python -B worlds_check.py                     # код 0; 22 проверки «да» (24 — с SOURCE_BOOK_YAML)
SOURCE_BOOK_YAML=<assumptions.yaml книги-источника> python -B worlds_check.py   # + сверка блока worlds и joint
python -B build_calendar.py                   # код 0; «прошло 140 из 140»; пишет H\book-draft\calendar.json
python -B verify_worlds_calendar.py           # код 0; «проверок 350, провалов 0»
```

Переменные: `LENTA_WORLDS_DIR` (копия записи, по умолчанию `<book-draft>/worlds`), `LENTA_WORLDS_FRAGMENT`, `LENTA_PRIMARY_DIR` (первичка, по умолчанию `<H>/reference/primary`), `LENTA_CALENDAR_OUT`, `LENTA_BOOK_KEYS` (список ключей книги, по умолчанию `<H>/study/magnit_book_keys.txt`).

Ручная сверка без скриптов листа:
1. `sha256sum H/book-draft/worlds/*` — значения таблицы README §1; `worlds_source.json` начинается с `7296567d`.
2. Скопировать `worlds_inputs.yaml`, `worlds_recipe.py`, `worlds_source.json` во временный каталог; `python -B worlds_recipe.py --check` → «воспроизведено: 63 строк, кривые ['H', 'M', 'N'] — совпадают с worlds_source.json».
3. В песочнице порта (`H\port-check\work`, её venv): `python -B ops/tools/refresh_worlds.py --check` → «… совпадают … строго», код 0.
4. `git -C <репозиторий книги-источника> show origin/v5:data/assumptions/worlds_source.json | sha256sum` = `7296567d…` (побайтовость копии; только чтение).

## Что ломает лист

- Нормализация CRLF → LF в каталоге книги (`.gitattributes` без `-text`): sha256 `worlds_source.json` станет `99cdd4ff…` — проверка 1 падает.
- Любая правка шести файлов записи (включая комментарии) — sha256 меняется; `--check` правку комментария не заметит, закрепление заметит.
- Изменение весов/λ во фрагменте без изменения записи — проверки «joint = запись», F.
- Сдвиг даты отчёта компанией — когда компания объявит дату 3 кв., событие переводится в `day` (сборщик календаря IR, раз в неделю); проверка центра 29.10 заменяется на объявленную дату.
