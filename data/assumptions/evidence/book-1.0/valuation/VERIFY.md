# VERIFY — лист «Оценка» (раздел 09), книга 1.0 «Ленты»

## Как воспроизвести

Python 3.12 из venv `book-draft\.venv` (openpyxl, pypdfium2, PyYAML). Сеть не нужна: `fetch_iss.py` без `--fetch` только печатает sha256 сохранённых выгрузок. Все пути — через переменные окружения. Умолчания выводятся от места скриптов, абсолютных путей в коде нет.

```powershell
$env:PYTHONIOENCODING = 'utf-8'
# необязательно: $env:LENTA_PRIMARY_DIR, $env:LENTA_RESEARCH_DIR, $env:MAGNIT_850OA_DIR, $env:X5_DATABOOK
cd <handoff>\book-draft\evidence\book-1.0\valuation
..\..\..\.venv\Scripts\python.exe -B fetch_iss.py          # sha256 сверочных выгрузок ISS (с --fetch — перекачать)
..\..\..\.venv\Scripts\python.exe -B x5_extract.py         # нужен датабук X5; без него хватает сохранённой inputs\x5_ias17.json
..\..\..\.venv\Scripts\python.exe -B beta.py               # → out\beta_out.txt / .json
..\..\..\.venv\Scripts\python.exe -B governance.py         # → out\governance_out.txt / .json
..\..\..\.venv\Scripts\python.exe -B market_headline.py    # → out\market_out.txt / .json (читает out\beta_out.json)
..\..\..\.venv\Scripts\python.exe -B verify.py             # 35 проверок; код 0 — все «ДА»
```

Порядок важен: `market_headline.py` читает `beta_out.json`. Полный прогон занимает ≈15 с. Расчёт детерминирован (зерно 20260918): два прогона подряд дают побайтово те же `out\*` (проверено 28.09.2026).

**Входы с sha256** — в `out\*.json` → `sources`:
- первичка: датабук `0d290ed2…`; МСФО `ifrs_mkpao\*.pdf`; `moex_iss_lent_corp\iss_history_LENT_2026-06-26_2026-09-25.json`;
- сырые ISS 28.09.2026 из `research\_work05`: LENT `06bfbaa5…`, LNTA, MCFTR, IMOEX, X5, MGNT;
- `research\lent_sellside_targets.csv`;
- 850oa `beta_summary.json` и `assumptions_template.yaml`;
- соседние листы: `margin\anchor_out.json`, `facts\anchor.json`, `facts\peers.json`.

Если соседние листы изменятся, изменятся проформа LTM, k и строка аналогов «Лента (проформа)». После этого надо перезапустить `beta.py`, `market_headline.py` и `verify.py` и сверить фрагмент.

## Проверки, которые обязаны держаться (`verify.py`)

1. `market.price` = LEGALCLOSEPRICE LENT 18.09.2026 = 1 619,5 в живой выгрузке ISS и в research; CLOSE 1 625,5 во всех трёх файлах, включая primary.
2. `sellside_targets` = последняя цель каждого дома из CSV (9 домов), агрегаты сходятся, у каждой цели есть дата.
3. `peers`: EV/EBITDA совпадает с выводом, база одна (IAS 17).
4. `beta_u` 0,55 [0,45–0,70]:
   - кластер якоря на проформе внутри (0,50; 0,56);
   - месячные собственные β_u за 2/3 года внутри оси;
   - k отчётного периметра = 3,3274/4,0851 (лист 850oa).
5. ERP 5,57 % [4,9–6,7 %]; верх = (0,55·4,23 + 3,895 − 2,557)/0,55 = 6,663 %.
6. Дисконт за управление:
   - Σ sign·value компонентов = `governance_discount` = 0,0525 = вывод `governance.py`;
   - компоненты совпадают с каналами (значение и знак);
   - есть канал со знаком минус;
   - утечка через капитал 2022–2024 = 1,418702;
   - ставка займов 2П2025 ≥ 16 %.
7. Заголовок:
   - метод `intrinsic`, диагностики `median`, шаг 50;
   - пороги совпадают с выводом;
   - при V0 = 1,3·D и σ√T 0,30 опционная часть меньше 50 ₽;
   - в книге нет σ, K′, `strike_premium`, `credit_share_c`, `strike_decay`, `recalibration_flag`, `option`.
8. `terminal_real_growth`, `roll_along_forwards`, `distress`, `market_curve_years`, `ronic_spread`, `terminal` и правило полосы совпадают с 850oa.
9. Диапазоны осей полосы = строки чувствительности = обратный DCF; центр каждой оси внутри диапазона.
10. В скриптах нет абсолютных путей пользователя.

3. **k.** ВП/EBITDA X5 LTM = (274,942 + 303,185 + 286,939 + 307,445)/(71,708 + 78,647 + 62,408 + 74,258) = 4,0851. Датабук X5: «Profit and Loss», стр. 8, и «EBITDA», стр. 22, колонки 25–28 (IAS 17). «Лента»: датабук PL, строки 12 и 49: FY2025 − 1П2025 + 1П2026 = 280,937/84,433 = 3,3274.
4. **Проформа.** 84,433 + 1,168 + 0,0206·75,43 + 0,0099·22,90 = 87,38. ВП: 280,937 + 0,2239·(56,761 + 75,431 + 22,904) = 315,66. 315,66/87,38 = 3,612; /4,0851 = 0,884; ×0,601 = 0,531.
5. **EBITDAR с арендой.** β_ops X5 = (0,601·911 + 0,1·677)/1 588 = 0,387; k_R = 2,385/2,461 = 0,969; β_u = (0,387·0,969·463,1 − 0,1·159,3)/303,8 = 0,520.
6. **Займы.** МСФО 2023 v2, с. 60 — 567 578 и 530 341; МСФО 2024, с. 58 — 320 783; МСФО 2025, с. 41 — 10 470 000, 1 063 698, 11 533 698; МСФО 1П2025, с. 14 — 4 500 000, 184 986; МСФО 1П2026, с. 14 — 11 875 152, 341 454. Ставка 2П2025 ≥ 0,878712/(0,5·(4,684986 + 5,97)) = 16,49 %.
7. **Ключевая 2П2025.** По таблице ЦБ: 20 % до 27.07, 18 % до 14.09, 17 % до 26.10, 16,5 % до 21.12, 16 % дальше. Среднее по календарным дням 01.07–31.12 = 17,50 %.

9. **g.** 0,010 + 0,010 + 0,035 + 0,0075 − 0,010 + 0 = 0,0525.
10. **Порог limited_liability.** Колл Мертона при ставке 0: C/D = x·N(d1) − N(d1 − s), d1 = ln x/s + s/2. При x = 1,3 и s = 0,30 C/D = 0,3358; опционная часть 0,0358·131·10⁹/115,074675·10⁶ = 41 ₽.
