# VERIFY — лист «Маржа» (книга Ленты 1.0)

## Как воспроизвести

Python 3.12, окружение `H\book-draft\.venv` (openpyxl 3.1.5, PyYAML 6.0.2, pypdfium2). Первичка — `LENTA_PRIMARY_DIR` (по умолчанию `H\reference\primary`, вычисляется от расположения скриптов).

```
cd H\book-draft\evidence\book-1.0\margin
set PYTHONIOENCODING=utf-8
..\..\..\.venv\Scripts\python.exe run_all.py
```

`run_all.py` прогоняет по порядку `series.py → anchor_bridge.py → ltm_pro_forma.py → ar1.py → refclass.py → regimes.py → lease_labor.py → update_demo.py` (каждый пишет `<имя>_out.json` и `_out.txt`) и сверяет фрагмент `H\book-draft\fragments\margin.yaml` с выводами. Код 0 — все 25 проверок «ДА». Время ≈20 с (Монте-Карло 200 000 прогонов). Сеть не нужна. Скрипты можно запускать и по одному в том же порядке (каждый читает выводы предыдущих).

## Проверки, которые обязаны выполняться

Первичка и тождества (скрипты падают при нарушении):
1. sha256 датабука = строке MANIFEST (`series_out.txt`, строка 2): `0d290ed2…3339`.
2. Сумма кварталов листа «Financials quarterly» (IAS 17) = полугодию листа PL: |Δвыручка| ≤ 0,5 млрд, |ΔEBITDA| ≤ 0,15 млрд за 2020H1–2026H1 (факт: ≤ 0,001).
3. Доход от выгодной покупки FY2024 одинаков в ДДС обеих баз (1,1146 млрд).
4. Мост якоря: проформа выручки 648,488 + 66,121 − 9,360 = 705,249 (±0,01); принятый долг «О'КЕЙ» 50,896; аренда «О'КЕЙ» 17,636; аренда и права пользования «О'КЕЙ» + «Дом Лента» = приобретённые по прим. 7 (28,494 и 32,211); выручка «Дом Ленты» прим. 5 = датабук (±0,05).
5. Сверка денежной аренды 1П2026: платежи по базам 19,260 = прим. 7 (7,758 + 11,501).

Фрагмент против листа (`run_all.py`):
6. `facts.anchor.margin_pro_forma` = медиана Монте-Карло (±5e-5); `margin_pro_forma_se` ≥ sd Монте-Карло; наблюдение 2026H1 в `joint.regime_update.observations` = им же; `facts.ebitda_pre16.pro_forma`, `facts.anchor.ebitda_ltm`, `revenue_ltm` = `ltm_out.json` (±0,01).
7. Цели режимов = `regimes_out.json` (±5e-5); цели "2026H1" равны у всех режимов; цель "2026H1" + `seasonal_h1_pp` = наблюдение якоря; с 2027 г. стресс < дно < частичный < полный; «полный» LT в 7,5–8,0 %.
8. Вероятности одинаковы в N/H/M, = `refclass_out.json → book`, сумма 1; класс эпизодов воспроизводит 850oa (5/3/2/0 из 10).
9. `sigma_pp`, `deviation_persistence` = `ar1_out.json → choice`.
10. `quarter_offset_pp` = `series_out.json → offset_pp_book` (±5e-5) и обнуляется внутри полугодия на долях `revenue.quarter_share` фрагмента «Сеть» (|Σ| < 1e-5; без фрагмента — на исторических долях листа).
11. `seasonal_h1_pp` = `regimes_out.json`; A-C6 — между двумя медианами листа (±1e-4); доля труда и κ — `lease_labor_out.json`; `leased_share` = 1 − доля собственной площади 1П2026.
12. Гайденс-проверка: нужная маржа 2П2026 в 7,6–7,9 %; `demo_values` 5,0–8,0 % и покрывают ожидание модели; дрейф E[m_LT] после отчёта по предиктивному распределению |·| < 0,01 п.п.
