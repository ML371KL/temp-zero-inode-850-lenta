# Доказательные листы книги

Каждое число книги, которое не прочитано из отчётности напрямую, выведено скриптом листа. Лист = каталог `book-<версия>/<тема>/`: скрипты, `README.md` (что лист утверждает, основания, диапазоны, цена ошибки, открытые вопросы), `VERIFY.md` (как воспроизвести и какие инварианты держатся), выводы скриптов (`*_out.*`, `out/`).

**Первичка** (PDF, XLSX) в репозиторий не кладётся: скрипты читают её из каталога `LENTA_PRIMARY_DIR` и сверяют sha256 с `MANIFEST.md` первички (вне репозитория). Сырые ответы ISS и сводки исследований — `LENTA_RESEARCH_DIR`; листы, опирающиеся на записи книги-источника (якорь β X5, класс эпизодов маржи), читают её каталог через `MAGNIT_850OA_DIR` (только чтение). В CI листы не исполняются (DESIGN §1); их выводы — часть доказательства и лежат рядом.

## Книга 1.0 (`book-1.0/`)

| Лист | Что дал книге |
|---|---|
| `facts/` | база фактов `data/facts/*.json` и `docs/FACTS.md` (sha256 первички, страницы, 270 тождеств); `canon.py` — канон проформы якоря (EBITDA LTM одним каноном, решение ведущего A12) |
| `worlds-calendar/` | проверка записи миров (D6), календарь `data/calendar.json` |
| `network/` | сегменты сети, эффективная площадь и закрытия истории, пути площади, центральная клетка выручки (`revsim.py`) |
| `margin/` | маржа якоря на проформе (мост), ряды, AR(1), режимы, классы вероятностей |
| `capex/` | поддерживающий capex снизу вверх, capex открытия, D&A якоря |
| `nwc-tax/` | определение ОК, старт и июньский излишек, касса, налог, запертые убытки, налоговая амортизация |
| `financing-bridge/` | реестр долга, корзины ставок, дивидендная лестница, строки моста, квартальные веса переката |
| `valuation/` | β_u, ERP, каналы дисконта за управление, аналоги и цели домов |
| `assembly/` | сведение листов: `regime_targets.py` — цели режимов с явным слагаемым «Дом Ленты» (решение ведущего C17), `rescale_capex.py` — знаменатель поддерживающего capex |

Сравнения с 850oa в листах — методические (правило, конструкция); числа оценки книги-источника в репозиторий не входят (решение ведущего F33).

## Книга 1.1 (`book-1.1/`)

Версия 1.1 суждений не меняет — листы тем остаются в `book-1.0/`. Листы версии считают ядром на книге из репозитория, первичка им не нужна (`book-1.1/README.md`).

| Лист | Что дал книге |
|---|---|
| `walk/` | прогулка 1.0 → 1.1: четыре ключа книги по одному, эффект каждого на точку, медиану и полосы (`V1.1-CHANGES.md`, раздел 2) |
| `gates/` | развёртка масс гейтов по 286 датам оценки и величины текстов `gate_explanations.yaml` |

## Книга 1.2 (`book-1.2/`)

Версия 1.2 меняет только миры ставок (общая запись 28.10.2026 после решения Банка России 23.10.2026) и дату их кривых; листы тем остаются в `book-1.0/`, лист записи миров — у книги-источника (`book-1.7/worlds/` 850oa). Листы версии считают ядром на книге из репозитория (`book-1.2/README.md`).

| Лист | Что дал книге |
|---|---|
| `worlds/` | таблицы раздела 2 на обеих записях (`worlds_tables.py`) и быстрые числа версии — цена окна снимка, итоговой ОНДКП и факта продовольствия (`quick.py`) |
| `walk/` | прогулка 1.1 → 1.2: мир M, затем миры N и H — эффект на точку, медиану и полосы (`V1.2-CHANGES.md`, раздел 2); блок миров книги 1.1 для проверки «книга 1.2 с мирами 1.1 = книга 1.1» |
| `gates/` | развёртка масс гейтов книги 1.2 по датам оценки и величины текстов `gate_explanations.yaml` |
