# Доказательные листы книги 1.1

Версия 1.1 (06.10.2026) суждений, фактов и миров не меняет: листы тем — `../book-1.0/`. Здесь два листа самой версии — переход 1.0 → 1.1 по правкам и числа объяснений гейтов. Первичка не нужна: оба листа считают ядром на книге из репозитория.

| Лист | Что утверждает | Вывод |
|---|---|---|
| `walk/` | переход 1.0 → 1.1 — четыре ключа книги, включённые по одному; последний шаг равен прямому расчёту книги 1.1, книга после шагов — книга 1.1 целиком | `walk/out/walk.txt`, `walk/out/walk.json` |
| `gates/` | массы гейтов книги 1.1 на каждой дате оценки с 18.09.2026 по 30.06.2027 (286 дат) и величины, которыми оперируют тексты `gate_explanations.yaml` | `gates/out/gate_sweep.txt`, `gates/out/gate_sweep.json` |

## Как воспроизвести

Из корня репозитория, Python 3.12 (`.venv`).

```
# прогулка: стартовая книга — версия 1.0 по тегу
git show book-1.0:data/assumptions/assumptions.yaml > var/book-1.0.yaml
python -B ops/tools/walk_book.py --start var/book-1.0.yaml --end data/assumptions/assumptions.yaml \
    --steps data/assumptions/evidence/book-1.1/walk/steps.yaml --median \
    --json data/assumptions/evidence/book-1.1/walk/out/walk.json > data/assumptions/evidence/book-1.1/walk/out/walk.txt

# развёртка гейтов
python -B data/assumptions/evidence/book-1.1/gates/gate_sweep.py
```

Прогулка — ≈5 минут (шесть полос по 2 000 прогонов), развёртка — ≈1,5 минуты на 8 ядрах. Оба расчёта детерминированы: зерно полосы — `valuation.uncertainty.seed`.

## Что обязано держаться

1. Прогулка заканчивается двумя «ДА» (код 0): «последний шаг = прямой расчёт конечной книги» и «книга после шагов = конечная книга целиком». Шаг «Версия 1.1» чисел не меняет; шаг A01 не меняет точку (оси полосы точку не трогают).
2. Книга 1.0 воспроизводится ключами версии 1.0 бит в бит: `tests/test_book11_walk.py` (точка 3 270,502314484846 ₽ и медиана 3 130,6253318118447 ₽ при снятых `axis_merge`, `boundary_levels`, `tax_floor` и `da_convention: cohort_runoff`; старт прогулки — те же числа).
3. Терминал каждой из 36 клеток книги 1.1 равен прямой сумме по полугодиям (D&A по когортам, налог с нулевым пределом, щит как разность налогов) — `tests/test_ext_audit_terminal.py` (все 36 клеток, допуск 10⁻⁹; фактическое расхождение не больше 7·10⁻¹⁴).
4. На развёртке нет ни одной даты с блокирующей находкой и ни одной даты, где масса гейта выходит из коридора своего объяснения (первые две строки `gate_sweep.txt`); опорные даты развёртки проверяет `tests/test_gates_and_blocking.py::test_the_book_explanations_hold_without_a_daily_alarm_until_their_deadline`.

## Что показала развёртка (книга 1.1 против 1.0)

Массы на дату книги те же: `ev_ebitda` 0,518 (17 клеток), `terminal_share` 0,032 (3 клетки), `guidance_gap` 1,0. Сдвинулись даты дрейфа: 18-я клетка `ev_ebitda` (N × дно × высокий capex, 5,94× у края 6,0×) выходит за коридор с 22.02.2027 (в 1.0 — с 21.02.2027); четвёртая клетка `terminal_share` (N × дно × низкий capex) — только 01.01.2027 (в 1.0 — 31.12.2026–04.01.2027). Минимум доли терминала — 12,3 % (N × стресс × высокий capex; в 1.0 — 13,2 %): предел налога по каждому полугодию снимает с клеток «стресса» возврат налога и щит на налог, которого нет. Минимум капитала клетки — +38,2 млрд ₽ (в 1.0 — +38,7).
