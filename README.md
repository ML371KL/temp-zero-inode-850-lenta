# Лента 850 — модель справедливой стоимости акции МКПАО «Лента» (LENT)

Модель и дашборд https://tzi-850-lenta.pages.dev (в разработке). Логика, принципы и
практики — от модели Магнита 850oa: распределение, а не точка; явные обоснованные
допущения книги; честная мера неопределённости; обратный DCF «что заложено в цену»;
опережающие индикаторы ближайшего отчёта с зачётом.

## Состояние

Этап P1 — перенос ядра 850oa (книга 1.6) в общий вид: машина версий книги снята,
факты с нейтральными к дате якоря именами, строки моста и плановые выплаты —
общими списками книги, годы правил — ключами книги, ядро — чистая функция книги
(диск не читает), аналоги — данными книги, эмитент — `indicators/issuer.py`.
Поведение ядра доказано бит в бит на книге Магнита, переведённой в новую схему
(сверка — вне репозитория).

Книги Ленты (1.0) и фактов в `data/` пока нет: тесты, которым нужна книга,
помечены `needs_book` и исключаются выражением `-m` (см. `pytest.ini`).

## Устройство

- `model/` — ядро (`core.py`: полугодовой проход клетки, APV, мост), книга и её
  закрытая схема (`book.py`, `book_schema.py`), сетка и слои (`grid.py`),
  отображение V0 → цена (`mapping.py`), полоса неопределённости (`uncertainty.py`),
  движок и суждения (`engine.py`), таблицы книги (`book_results.py`), выпуск
  (`payload.py`, `checks.py`, `live.py`).
- `indicators/` — сборщики (реестр и его дисциплина в `sources.py`), хранилище
  рядов, журнал прогнозов и нау-каст.
- `ops/` — конвейер (`run.sh`, юниты systemd, сборка и публикация выпуска),
  ручные инструменты (`ops/tools/`).
- `web/`, `functions/` — витрина и дверь данных (перенесены как есть, адаптация —
  этап P4).
- `tests/` — тесты; `pytest.ini` — маркеры.

## Запуск

```
python -m venv .venv
.venv/Scripts/python -m pip install -r requirements.txt     # Windows; на Linux — .venv/bin/python
python -m pytest -q                                          # без сети; с книгой 1.0 в data/
python -B -m model.book_results                              # таблицы книги: results.json, run_output.txt
python -B ops/tools/render_numbers.py --check                # числа текстов = results.json
```
